# Contributing during preparation

Start with the [readiness document](docs/readiness.md). This repository currently
contains design and research, not an application to run.

Discussions and factual corrections are welcome. Original contributions
intentionally submitted for inclusion are licensed under [Apache-2.0](LICENSE),
as provided by Section 5, unless explicitly stated otherwise. Flag any different
terms before submission; material with unresolved licensing will not be merged.
Submit only material you have the right to contribute under the applicable terms.
Contributors retain their copyrights. No copyright assignment or separate
contributor license agreement is required.

Implementation work should follow the first native-session proof described in
the readiness document; choosing a license does not expand the current scope.

For corrections, identify the exact upstream version, link to the supporting
source, and distinguish documented behavior from behavior actually tested.
Do not attach real credentials, private transcripts, personal paths, or customer
data. Third-party snippets require source and license review before inclusion.

Keep proposed features tied to a concrete user action and its acceptance evidence.
Avoid introducing infrastructure before the first native-session proof needs it.
