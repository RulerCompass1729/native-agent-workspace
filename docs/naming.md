# 产品命名草案

As of 2026-10-17。产品名未选定。`native-agent-workspace` 仅为仓库工作名，不是正式品牌；不购买域名、不申请商标、不制作 logo。

命名应能同时装下单 agent、协作、工作与生活，易念、易输入，不借用 provider 品牌，也不把普通用户带进“编排/fleet/harness”的术语。名称不必把全部功能解释一遍。

## 值得继续推敲的中文方向

| 名称 | 为什么适合 | 需要验证的问题 |
| --- | --- | --- |
| **同席** | 真人与 agent 可以坐到同一张桌旁；加入与离开很自然，亲切易懂 | 偏重多人，需要确保独自工作也自然；词已有其他场景使用，不能当可注册结论 |
| **合页** | 一页可独立、多页可连接；隐喻会话身份保持，合与分都顺手 | 通用五金词会影响搜索识别；英文不能直接沿用已知品牌 Hinge |
| **随间** | 空间随人的习惯变化，可独处也可协作；不限定编码 | 听写可能不直观，需要少量真实口述验证 |

这些是早期方向，不是创始人选定的品牌。英文品牌应独立推敲，避免硬翻中文或生造难念词。

## 新一轮品牌方向

创始人认为 Native Workspace / Workplace 适合作工程名，但正式名称需要更有品牌感。当前仍不改仓库、应用标识或数据目录。

| 候选 | 创意意象（不是词源或法律结论） | 取舍 |
| --- | --- | --- |
| **Tessune** | 独立的片段拼合，形成自己的节奏 | 短、抽象、扩展空间大；首次看到时需要建立读音 |
| **Coestra** | 多种声音合奏，人决定如何进行 | 协作感强；不应让单 agent 用户误以为必须组队；已发现其他行业同名使用 |
| **Liltspace** | 轻快、顺手、按自己的节奏工作的空间 | 亲切，覆盖工作与生活；名字比前两个长 |
| **栖间** | 会话有自己的位置，随时回来继续 | 中文意象自然；尚未做同名与商标筛查 |
| **合弦** | 每根弦独立，需要时一起奏响 | 协作隐喻明确；与“和弦”同音，需要测试听写与搜索 |
| **伴屿** | 各自独立，也能相互陪伴、连接 | 更偏个人生活与学习；尚未做同名与商标筛查 |

英文前三个仅完成一般网页和 GitHub 仓库名称初筛，未完成商标、域名或应用商店的正式排查。2026-10-17 GitHub `in:name` 检索：Tessune 与 Liltspace 返回 0；Coestra 返回近似名称 `coestrat`。这些数字会变化，0 个结果不证明名称可用。

这一轮不继续推荐 Sideweave、Meldra、Weftly、Parloft、Kinweave、Vellune 和 Weavlet：检索发现现有软件或应用使用。Sideweave 在普通网页搜索中未明确出现，随后 GitHub 直接检索发现同名项目，说明只依赖一次搜索不足以定名。

## 初步排除的英文词

实际公开检索发现 Sidefold 已用于软件/服务，Kinleaf 已用于应用，Roomloom 已用于应用。这些即使听起来贴切，也不应当作现成独占品牌采用。

- [Sidefold 官方产品](https://sidefold.co/about)
- [Kinleaf 官方产品](https://www.kinleaf.app/)
- [Roomloom / Cozy Designer 应用页](https://play.google.com/store/apps/details?id=com.coralbyte.roomloom)

本轮搜索也没有提供“同席/合页/随间可以注册”的证据。没有搜索结果不代表没有权利人；GitHub 名称、域名与应用商店可用性也不等于商标许可。

## 定稿时的最小步骤

先选两个方向做发音、听写和场景测试；再对目标市场的商标类别、相近读音、应用商店、GitHub 和域名做正式排查。品牌清晰度与可保护性优先于把仓库今天改成一个好听的词。
