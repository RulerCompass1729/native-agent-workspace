## The review record is one file per day; docs/review.md is frozen (2026-11-13, Claude 2)

**Why.** The push guard (`scripts/privacy_guard.py`, `MAX_BLOB`) refuses any
single file over 2 MiB. On main, `docs/review.md` was 895,734 bytes after the
last commit of 11-10 (3adba67d), 1,377,391 after 11-11 (326a160a), 1,521,229
after 11-12 (25fd89d3) and 1,631,140 at 42a122ad (11-13, midday), so a push
would have been refused within about two days. Every edit also added a whole
copy to history: 934 distinct versions reachable from main, 643.1 MiB, about
half of a full-history scan. The guard's limit is the person's hard gate and is
not changed here.

**Change.**
- New records are appended to `docs/review/YYYY-MM-DD.md`, one file per day by
  `date +%F` on this machine. A day at the recent rate is a few hundred KB, so a
  day file stays far below the limit and each edit adds a small version to
  history.
- `docs/review.md` gets one paragraph at the top pointing here; nothing in it is
  removed or changed. It is frozen as main had it at ee808a73 (1,635,857 bytes,
  1,636,090 with the paragraph). A correction or status change to an entry there is a new
  record in that day's file, naming the entry.
- CLAUDE.md: the three places that told agents to write `docs/review.md` (the
  reviewer brief, recording a reviewer's findings, the evidence rule) now say
  "the review record", and a new rule says where it is, that `docs/review.md`
  is frozen, and how to merge (below). README's document map points to
  `docs/review/` and to the earlier records.
- References that cite something already in `docs/review.md` are unchanged:
  `docs/{alpha,architecture,core-milestone,interaction,live-progress,product,readiness,testing}.md`
  and a comment in `scripts/test-native-tools.cjs`. Each points at an entry or
  row that stays in the frozen file, and its first paragraph points here.
  `docs/core-milestone.md` also says to keep findings "in the existing
  `review.md`"; that instruction belongs to the alpha.23 increment, closed on
  2026-10-18, and is left as written.
- `app/tests/docs-size.test.cjs` (full suite) fails when `docs/review.md`
  differs from its frozen copy (sha256) or is missing, and when any other file
  under `docs/` passes 1.5 MiB. Checked to fail: one byte appended to
  `docs/review.md`, one byte changed in place (same size), the file moved away;

**Merging.** Lanes started before this change may still add to
