## Human decisions enter the existing butler event stream

Successful authenticated desktop responses, authenticated mobile queue resolutions, saved human grants and background-card permit/reject/expiry facts now enter the existing ledger as field-projected request events. Only opaque object references and fixed action/outcome labels are recorded; form scopes, answers, card bodies and terminal content are excluded. A permission fact is not an execution proof. Historical grants and card settlements deduplicate across reloads, and transient ledger failures retry the event without re-executing the original operation.

The dispatcher observes these facts through its existing state path, including with no open page. Native identity, readiness, human quiet time, rotation controls, excluded models and the one-minute wake interval are unchanged. The intake adds no model call, timer, approval endpoint or persistent store. Tests exercise the actual desktop IPC and confirmation-settlement callback, mobile authorization negatives, expiry, identity-unavailable facts, coalescing, idle observation and a missing-hook mutation. Legacy extracted fixtures now load the new observer dependency without removing their original behavioral checks.

This is a local delivery for independent review, not an installed incident closure. Live-operation retries are bounded and in memory: an application crash during a ledger write failure may lose an otherwise non-reconstructible response event; saved grants and live card settlements replay from their existing durable metadata. Exhausting the retry bound leaves intake blocked rather than claiming completeness. A pre-existing unresolved rotation episode still blocks native wakes; this change does not release it.
