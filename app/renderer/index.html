数据、权限与退出

本应用保存对话副本、草稿和会话信息，不提供云同步、遥测或远程崩溃上传。UI 网络请求限定为本机服务；原生 agent 可以连接其模型服务，并按原生权限运行工具。

登录由原生 Claude / Codex 管理，本应用不复制它们的凭据文件。原生权限继续生效；加入或脱出协作不改变工具已有的文件访问权。

剪贴板只在你使用粘贴时读取，不监听剪贴板。退出协作不能撤回已经分享的内容。

关闭界面后，原生会话继续运行。重开界面不会自动重发任务；电脑重启或原生进程丢失后，活跃团队无法保证恢复。

本地副本没有应用层加密；同一系统账户下有文件访问权的程序可能读取它们。记录保留到你移除，删除本应用记录不会删除原生历史或提供商端记录。

结束会话后，可在“会话与原生团队”中移除本应用记录；共享记录需单独清除。
