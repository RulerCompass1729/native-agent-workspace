继续已有 Codex 会话

选择原生历史，保留原会话身份。请先结束其他地方的连接；这里不会重发旧任务。活动团队和目标不会自动重建。

列表仅在你打开时读取本机原生索引，不扫描文件夹。继续时读取所选会话的历史和原设置，不调用模型；原生自身仍可能恢复后台活动。

开始前的准备

本试用版使用你自己安装的 Claude Code 或 Codex，以及 Python 3。登录在原生终端中完成。

共同工作的参与者

加入不会共享私人历史。脱出后仍可独立继续；已经分享的内容会保留。

重命名会话

名称用于本机显示；主动授权一起核查时，会作为来源标签分享给所选成员，原生会话保持不变。

最多 60 个字符

邀请已有会话

只建立成员关系；不复制会话、不发送历史。

归档

归档保留记录，不结束原生任务。恢复会话回到原来的身份；恢复工作区找回原成员（单独归档的除外），不重发任务。原生进程已丢失时仍需明确继续原生历史。

共享笔记

把共同目标、决定和待办留在这里。本机保存；只有明确附到消息发送后，agent 才会收到。脱出后仍可查看，已发送内容留在原生会话。保存版本会留在共享记录；清空当前笔记不会删除旧版本。

协作背景

以下是成员状态与共享笔记，不含私人历史。可编辑后加入草稿，或复制到原生终端。只有发送时才占用模型上下文；不会另开一轮通知。
